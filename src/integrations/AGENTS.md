# 外部集成层规范

继承 [宿主源码规范](../AGENTS.md)。实际实现见 [README](README.md)。

- 承载 Host 对网络节点、契约插件和其他外部提供方的适配，不复制 Core 权威状态机。
- 所有调用保留显式身份、契约版本、allowlist、超时、取消、容量和 Unknown。
- 恢复适配器实现 Core 注入能力并可靠保存聚合提案，Harness/监控适配器消费 Host 契约；不得开放绕过审批的写入口。
- 插件/节点输出是证据或只读数据，不产生权限、许可或业务恢复事实。
- 新增实现前读取具体子目录 README，并同步 Host 架构、配置和测试文档。
