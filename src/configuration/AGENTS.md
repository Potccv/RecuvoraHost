# 宿主配置规范

继承[宿主源码规范](../AGENTS.md)。

- 本目录负责部署配置读取、相对路径解析、活动配置与宿主源码/安装/控制路径保护，以及向 Core 领域配置的转换。
- 配置加载和路径准备不得启动服务、连接节点、产生审批、签发许可或派发修复。
- Core 继续拥有领域配置不变量、审批范围与状态转换；权威存储的文件身份检查由 Host persistence 维护。
- Host 必须补充消费应用源码、安装目录、令牌、UI 构建和外部信任文件保护，不能依赖 Core 推测这些路径。
- 修改字段时同步 `profiles/`、`docs/configuration.md` 与相关测试。
