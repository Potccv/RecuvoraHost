# 宿主源码规范

继承[项目规范](../AGENTS.md)。

- 通过 recuvora_core 公开接口使用恢复引擎；本库 control 维护故障台账，适配器提供可信能力和提交，不另建授权或阶段决策通道。
- boot 负责可信应用装配，configuration 负责配置加载和控制路径保护；application 拥有服务生命周期、操作受理、回执与取消，recovery 实现 Core 恢复能力及聚合提交。
- cli 负责有界参数与输出，presentation 负责无副作用视图转换，server 负责 HTTP 身份、路由与响应映射；应用服务不得反向依赖 server 或 HTTP 类型。
- 恢复服务不得依赖具体节点后端；integrations 通过恢复能力契约提供外部适配，通用传输发送门不得解释恢复动作。
- 程序入口保持轻量；不新增 UI/Tauri、节点启动角色或与 Core 并存的业务实现。
- 请求取消后继续处理在途结果，先停止新调用、再等待当前任务结束并释放服务；不把断连或丢弃 future 当成确定取消。
- 活动配置、目标与宿主/核心源码、安装、状态、令牌及 UI 输出须隔离；保护信息来自可信装配。
- 测试集中于项目 tests，不在源码创建测试数据或构建生成物。
