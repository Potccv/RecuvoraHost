# 旧恢复存储迁移

本目录由上级 [legacy.rs](../legacy.rs) 管理。`bundle.rs` 负责冻结恢复、审批、知识和故障日志，将完整旧历史交给 Core 校验，保存新格式日志后原子安装恢复入口。

原恢复目录和 `recovery.lock` 对象继续绑定共享目标所有权。激活后的入口指向同目录内的新存储代次，原恢复日志保存在代次内，其余来源日志保持不变；旧版本不能将新入口解释为可执行的旧历史。监控目录由迁移结果返回，维护调用方显式选择，不改写活动配置。

接口、前提与不支持的历史见[持久化说明](../README.md)，实际验证与剩余限制见[实现状态](../../../docs/status.md)。
