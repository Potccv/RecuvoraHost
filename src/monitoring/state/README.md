# 观测状态与证据提交

本目录维护单个监控实例的状态机，不启动来源调用，不授予修复权限。外部 API 仍由 [monitors](../README.md) 重导出。

- `mod.rs`：生成受绑定参数的观测请求，维护健康、时效、覆盖和连续样本计数，产生有序故障信号，并原子提交故障信号与批末检查点。
- `checkpoint.rs`：绑定来源身份，保存代次、游标、序号、去重 ID 和已退役代次，重启恢复时清除运行期健康与计数。
- `validation.rs`：在状态转换前校验身份、游标、字段范围、批内顺序、重复冲突、嵌套深度和证据总量。

规则比较由 `rules` 提供；轮询、取消和动态成员有效性由 `scheduler` 管理。成功保存到磁盘后才更新已提交检查点及发布视图，不能仅凭内存状态宣布故障解除。

发布视图时同步保存最后样本的单调新鲜度期限，供执行前事实查询即时判断过期。观察提交、时效更新与视图发布受登记同步锁保护，查询不能读到故障已更新而视图尚未更新的中间状态；期限不从墙钟或缓存的 Fresh 字样推导。

验证继续使用项目集中维护的 [监控测试](../../../tests/monitors.rs) 与 [协议监控测试](../../../tests/monitor_wire.rs)。约束见 [AGENTS.md](AGENTS.md)。
