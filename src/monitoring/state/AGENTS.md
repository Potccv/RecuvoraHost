# 错误接收状态约定

继承[监控规范](../AGENTS.md)，职责见[README](README.md)。

- 整批校验先于任何状态变更；同时核验批内及全部持久收据的身份冲突，不能靠有限近期窗口实现权威去重。
- 收据与检查点同次原子提交；写失败停止实例，成功之后才通知调度和发布视图。
- 不产生目标健康或故障解除事实。来源覆盖和时效不得修改错误收据；age_ms 为原始来源信息。
- source binding 包含协议语义，改变来源或重用旧规则检查点必须拒绝。退休代次不能静默遗忘后再次接收。
- 状态方法仅向 monitoring 域开放，不新增任意写检查点或伪造业务事实的公开入口。测试仍集中于项目 tests。
