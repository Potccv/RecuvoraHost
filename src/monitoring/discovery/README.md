# 可信模板驱动的目标发现

本目录把配置授权的发现清单映射到监控身份，具体来源仍由外部节点或可信来源实现。公开类型继续从 `monitoring::*` 导出。

- `config.rs`：发现定义、版本化清单、诊断视图及容量、保留参数、模板前缀的配置校验。
- `inventory.rs`：来源绑定与从磁盘恢复目标清单，先持久化新身份再发布和派发，通过递增在场代次拒绝旧观察结果；包含受在场约束的观测来源适配。
- `polling.rs`：发现轮询、调用期限、取消后等待原调用完成，以及监督与工作任务归还。
- `mod.rs`：目录内职责组合与既有类型重导出。

部分清单只能确认在场；只有有效完整清单可以确认缺失。删除不释放累计身份容量、不清空游标、不解除故障；重启身份在首次发现确认前保持待确认。登记和关闭复用监控共享登记同步锁，空清单不代表存储可以提前关闭。

完整清单确认缺失时，在登记同步锁内立即撤销该目标的修复前提新鲜度期限，无需等待下一次时效检查刷新视图。再次在场仍需有效的新观测，旧 Fresh 快照不能恢复执行前提。

配置与协议细节见 [监控说明](../README.md)，集中测试见 [监控测试](../../../tests/monitors.rs)，开发约束见 [AGENTS](AGENTS.md)。
