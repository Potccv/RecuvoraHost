# 目标发现开发约定

继承 [监控约定](../AGENTS.md)，职责见 [README](README.md)。

- 来源只能返回有界 target key，不能选择路由、规则、程序或任意参数；发现配置只消费可信模板。
- 新身份先持久化再发布和派发，累计身份限制不能由删除释放；绑定变更须使用新发现 ID。
- 非法、重复、超量或失败清单整体拒绝；有效部分清单只能新增或确认在场，完整无错清单才能确认缺失。
- 重启待确认与已确认缺失分开；在场代次与登记门共同拒绝删除后重现的旧响应，不得削弱启动宽限。
- 取消后等待原来源 future 收尾再归还 worker 所有权；登记、关闭和观察提交共享同一串行边界。
- 内部访问仅限 monitors 域；测试集中在项目 tests/，不添加来源私有实现或活动部署信息。
