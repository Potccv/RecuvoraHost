# 审批内部开发规范

继承[项目规范](../../../AGENTS.md)与[恢复规范](../AGENTS.md)，接口约定见[README](README.md)。

- 所有审批迁移保持纯计算，实时提案与历史恢复使用同一验证器，不加入存储、时钟、调度或外部能力调用。
- 审核和执行效果仅在可信调用方确认对应完整提案已原子提交后交付；恢复历史不得重新产生效果。
- 保留当前硬政策、完整操作绑定、审核尝试与截止时间、人工拒绝终态、一次许可、同目标互斥和 Unknown 核实语义。
- 许可字段与构造保持私有；完成使用拥有的许可，历史迁移不得成为实时许可构造入口。
- 配置和完整事件历史参与提交绑定；恢复拒绝记录版本号断裂、重复提交身份和非法状态迁移。
