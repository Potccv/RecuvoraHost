# 修复经验开发规范

继承[源码规范](../../AGENTS.md)与[恢复规范](../AGENTS.md)。公开接口见[README](README.md)，测试归属见[集中测试](../../../../tests/README.md)。

- 本域只进行确定性经验计算和查询；不得引入文件、存储客户端、外部异步调用、时钟读取或知识源生命周期。
- 经验 ID 精确幂等、实际动作与候选共享的不可变产物版本、失败和 Unknown 实际动作永久隔离，必须在实时提案与历史重放中使用相同校验。
- 所有权威变更先返回提交提案；调用方可靠原子提交并确认后才能安装状态，不将发送成功视为提交成功。
- 模型只提供报告和候选；可信经验断言与提交确认不得增加直接反序列化入口，历史重放也不能跳过领域校验。
- 产物采用中立类型与有界 JSON，不在 Host control 中加入脚本语言、平台或具体提供方解析。候选不继承业务验收，不产生执行权限。
- 精确条件及关键词匹配先于限额，排序必须稳定；失败和 Unknown 经验保留为可检索的负面参考。
- 不删除经验、不可变版本、幂等键、失败或 Unknown 事实以降低容量；历史完整性依赖可信调用方，并在接口说明中明确边界。
