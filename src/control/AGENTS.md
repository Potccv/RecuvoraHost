# 控制模块规范

继承[源码规范](../AGENTS.md)。本目录统一维护授权、提交绑定、状态转换、恢复和隔离。

- 人工和模型决定都必须通过硬政策；完整操作、当前版本、原审批期限、一次消费和同目标互斥不可绕过。
- 状态无未经校验的 Deserialize 入口；许可不可复制或反序列化。提案在可信持久层确认前不得释放效果。
- 实时准备与历史重放使用相同迁移校验，重放不得重发许可或外部动作。
- 失败和 Unknown 隔离先于知识交付持久保存；总结或交付重试保留身份且不重复修复。
- 通过 Core 公共函数进行匹配、请求生成和经验构造，不复制算法。Core 输出仅为业务数据，不能作为授权证明。
- 规则变动同步集中 control_* 回归、相关服务测试与[控制参考](../../docs/control/README.md)。
