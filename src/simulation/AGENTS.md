# 封闭模拟开发规范

继承[自愈业务规范](../AGENTS.md)，职责见[README](README.md)。

- 本目录只模拟固定无副作用动作，不调用真实能力，不增加任意执行器入口；模拟授权与正式审批分离。
- `actor` 是唯一任务状态权威；先同步日志再确认状态，取消与超时收回工作任务后才释放执行槽。
- 执行后不确定保留 Unknown 并阻断同目标，重启不重放；保留当前合法状态迁移与日志损坏处理规则。
- 内部命令、日志和调度方法只在 simulation 域可见；公开契约从 `mod.rs` 导出，不增加 Core recovery 的兼容导出或真实执行器。
- 测试放项目 tests/；日志和构建输出只写源码目录外，由调用方维护运行目录边界。
