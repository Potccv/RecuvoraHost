# CLI 规范

继承[源码规范](../AGENTS.md)。

- 严格限制参数数量、大小和命令组合，路径保留操作系统编码，文本要求有界有效 UTF-8。
- CLI 调用 Host 应用服务与 control 契约；不导入供应商实现，不自行签发许可，不通过模型输出构造操作员身份。
- 项目与可见性必须明确选择，实例失败不改派；Hidden 不表示离线，配置存在不代表节点已认证。
- 输出使用安全 JSON 编码，保留关联 ID、Unknown、禁止自动重试及业务未验证。展示代码不得产生额外副作用。
- 人工批准只记录决定，apply 显式执行；check-result 仅核验，参数层不能绕过政策与持久状态。
