# 应用服务规范

继承[源码规范](../AGENTS.md)。

- 本模块提供与 HTTP/CLI 无关的应用协调；不导入 server、Axum 或 boot。装配由 boot 注入，禁止通过传输层反向获取配置或服务。
- HostRuntime 拥有受管服务和关闭顺序；Application 拥有已接受操作、回执、取消与共享能力访问。不通过 Deref 暴露或伪装传输层字段。
- Core 维护恢复阶段与授权规则。本模块不增加第二套业务阶段或许可，独立文本修复与封闭模拟保持既有明确边界。
- 先可靠保存操作接受记录，再派发；稳定 ID 拒绝重放。完成保存失败、断连和取消不证明副作用停止，保留 Unknown 与禁止自动重试。
- 自动恢复的执行和结果核实复用装配时绑定的后端；请求不能重新选择执行器、目标或信任配置。
- 先停止新调用，再请求取消并等待结果，最后关闭受管服务。保持兼容接口的模拟 Engine 独立关闭责任，不把释放句柄当作执行停止。
- 测试集中于 tests；传输层只查询操作记录，不取得可变 journal 或调用表。
