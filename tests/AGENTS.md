# 宿主测试规范

继承[项目规范](../AGENTS.md)。

- 测试集中于本目录，Cargo 目标显式登记；使用 Core 公开契约或 Host 测试内部接口，不复制 Core 私有实现。
- 保留 CLI 参数与输出、HTTP 身份/权限/revision、回执与Unknown、监控故障、只读插件/观测记录和静态目录边界回归。
- 节点替身使用 扩展协议 v1 网络会话协议，不通过已移除的stdio入口测试。
- 测试不依赖活动节点、真实令牌或供应商服务；子进程、回环监听和后台任务均有界并在结束时回收。
- 临时数据使用 RECUVORA_TEST_TEMP 的外部隔离目录，成功后清理本次创建且记录的路径；失败调查结束也须清理，不删除活动部署。
- 如测试需要现有核心库能力，通过依赖调用并保留权限边界；协议替身、HTTP回执和文本读回不代表真实业务恢复。
